🔒 How to set up Single-Sheet Sync (ZERO access to your other Google Drive files!) Click to toggle
Why this is 100% locked down: Our script uses Google's /** @OnlyCurrentDoc */ security tag inside a single Google Sheet. That means Google strictly jails the permission to ONLY that one spreadsheet — it has zero access to any other file or folder in your Google Drive!
  1. Click Copy Locked-Down Script below (or open google-drive-sync.gs in your project folder).
  2. Open a single blank Google Sheet by visiting sheets.new and name it Pulse & Flow Fitness Data.
  3. Inside that Google Sheet, click Extensions (top menu) → Apps Script.
  4. Delete the 3 lines in Code.gs, paste the copied script (make sure /** @OnlyCurrentDoc */ is at the top), and click Save (💾).
  5. Click Deploy (top-right blue button) → New deployment → gear icon ⚙️ → Web app.
  6. Set Execute as: Me, and Who has access: Anyone (protected by your Secret Sync PIN above).
  7. Click Deploy → Authorize access. Notice the permission screen now ONLY asks for: "View and manage spreadsheets that this application has been installed in" (zero Drive access!).
  8. Copy the Web app URL (ends in /exec) and paste it into the box above on your PC and Phone!
